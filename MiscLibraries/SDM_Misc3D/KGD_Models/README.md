# Recovered existing KGD model dependencies

These 13 STEP files were copied unchanged from the existing local `KadenGDesigns/Libraries/KGD_Models` library. Seven repair previously missing shared model references; six are dependencies of seven exact footprint assets imported from `KGD_Footprints.pretty`. Only required files were copied.

All embedded model headers and attribution are retained. That source library supplied no separate README or license document, so no new license grant is asserted here. Source paths, byte sizes, and SHA-256 hashes are recorded in [recovered-assets.json](../../validation/recovered-assets.json). The STEP files contain no detected external file-reference entities.

Footprint associations are preserved from their original source, including generic packages whose model filename names another component. This recovery establishes original-file identity and loading; it does not independently certify those historical mechanical associations. Do not substitute a different model based only on a similar package name.

Use `${SDM_MISC_3D}/KGD_Models/<exact-filename>`. No transform, pad geometry, pin number, or model file content was changed.
